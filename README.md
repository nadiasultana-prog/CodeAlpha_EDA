# CodeAlpha_EDA
Titanic ডাটাসেটের Exploratory Data Analysis।

## কী করেছি
- ডাটার গঠন ও missing value দেখে ঠিক করেছি
- লিঙ্গ, ক্লাস ও বয়স অনুযায়ী বেঁচে থাকার হার বিশ্লেষণ করেছি
- correlation বের করেছি

## প্রধান ফলাফল
- নারীদের বেঁচে থাকার হার 74%, পুরুষদের 19%
- ১ম ক্লাসে 63%, ৩য় ক্লাসে 24%
- শিশুদের হার সবচেয়ে বেশি

## ব্যবহৃত টুল
Python, Pandas, Seaborn, Matplotlib
